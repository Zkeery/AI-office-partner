AI办公搭子

AI 产品经理 / 产品负责人

面向知识工作的 AI 办公 Agent

核心维度：产品架构｜Agent 任务编排｜Context Engineering｜模型与 Prompt｜HITL｜质量与成本治理

项目概述

面向运营、项目及产品人员的 AI 办公 Agent，覆盖数据复盘、周报撰写与调研简报。结合任务编排、上下文管理与可复算分析，将原始材料转化为可编辑、可追溯的办公成果。

职责描述

负责 AI办公搭子从 0 到 1 的产品设计与研发落地，统筹需求规划、Agent 架构、模型与 Prompt 策略、交付体验及质量成本治理。

【需求洞察与产品规划】围绕数据复盘、项目周报、会议纪要等 6 类办公场景，拆解用户任务、输入约束与交付标准；负责 PRD、信息架构、场景优先级及异常分支设计，确立以任务和成果为核心的产品体系。

【Agent 架构与任务编排】设计 Plan–Execute 任务编排与状态机，定义文档读取、网页检索、数据计算及报告生成的工具契约；通过任务持久化、原子状态占用与执行令牌，支持暂停续跑、失败重试及定时／依赖触发，控制重复执行与过期结果覆盖。

【Context Engineering 与资料治理】设计显式材料绑定与任务上下文组织策略，整合用户指令、文档正文、表格计算结果和网页证据；通过材料快照、容量校验、来源记录及上游报告版本绑定，控制无关资料混入与信息遗漏，保证生成依据可追溯。

【模型接入与 Prompt 策略】定义 DeepSeek、GPT、通义千问与豆包的接入规范，设计场景化 Prompt、结构化计划输出及 Schema 校验；结合显式模型选择、任务型号锁定、错误分类与有限重试管理调用一致性，完成 DeepSeek 真实联调和成果验收。

【数据智能与人机协同】采用“程序计算＋模型表达”的分工，设计全量表格分析、可复算公式与原生图表；将成果审阅、章节级改写、版本对比／恢复及费用确认纳入 Human-in-the-Loop 机制，支持用户核对数据、干预生成并持续修订成果。

【质量评测与成本治理】建立覆盖需求、结构、语言、事实和长度的内容质量 Rubric，结合异常注入与 Bad Case 归因推动产品规则迭代；设计按任务／跑次归集的 Token 用量台账、预算预留与厂商 Usage 对账，明确未知用量及超限行为，支撑质量与成本分析。

项目成果

  1. 完成 AI办公搭子从 0 到 1 的产品设计与落地，覆盖 6 类典型办公场景，整合材料引用、任务执行、成果修订与 Word／Excel／PPT／Markdown 交付，形成可实际使用的个人 AI 办公工作台。
  2. 形成“确定性计算＋生成式表达”的数据交付能力，支持 CSV／XLSX 全量分析、复算公式与原生图表，并将章节编辑、版本追溯和周期任务整合至同一产品，使用户能够围绕同一成果持续核对、修订和复用。
  3. 建立 5 维内容评价与关键异常回归体系，将材料完整性、执行一致性、模型异常和预算边界转化为可检查的验收规则；完成 12 项可靠性专项优化，形成问题归因、策略修订与版本验收的质量迭代机制。
  4. 沉淀场景化 Prompt、工具契约、材料快照、报告版本、模型适配与评测资产，配套自动化材料继承和 Token 预算管理，为重复办公任务的标准化、场景扩展及后续成本分析提供可复用基础。
