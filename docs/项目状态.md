## 本机闭环定义（当前口径）

输入任务并选择模型 → 创建计划/添加材料 → 自动确认执行（费用超限等待用户确认）→ 真实报告与图表 → 下载或主动个人飞书导出 → 自动化跑次与站内结果。

普通用户界面保留定时、依赖触发、立即执行、启停和历史；Webhook 密钥、群通知配置、回调登记与应用身份导出没有用户入口，服务端能力保留。群通知仍默认关、真发暂缓。历史 1.24 个人 OAuth 真机验收记录保留，本轮没有重新执行对外导出。
