## 本机闭环定义（当前口径）

描述任务 → 添加材料/链接 → 按需要设置执行时间 → 系统自动判断场景、规划与执行（费用超限仍等待确认）→ 真实报告与图表 → 修改、下载或主动个人飞书导出 → 自动化跑次与站内结果。

自动化的材料快照/最新文件、上游成功跑次固定报告版本及每跑次内部额度保护保留为管理能力；普通用户无需理解或配置这些策略。每次请求前预留内部额度，未知用量不释放预留；普通任务保留估算软闸门和费用确认。暂停、中断与失败均为独立状态，不记作成功。前轮回归不等于所有业务内容均已由真实用户验收。

普通用户界面保留执行时间、立即执行、启停和结果历史；依赖触发、模型/技能/专家、预算、材料策略及技术统计集中于管理能力。Webhook 密钥、群通知配置、回调登记与应用身份导出没有普通入口，服务端能力保留。群通知仍默认关、真发暂缓；历史 1.24 个人 OAuth 真机验收记录保留，本轮不据此宣称重新外发验收。
