## 1. 目标用户与核心任务（相对 1.0 的变化）

- **谁**：仍是个人职场人（先自用）；暂不做企业多人。
- **对标姿态**：学 WorkBuddy——**本机可执行、可交差的个人办公搭子**（不强制绑定腾讯生态）。
- **核心任务（扩面后）**：用自然语言或场景入口下任务，系统拆步骤并交付**可验收的办公成品**，覆盖：
  - **写类**：周报、会议纪要、**邮件稿、方案模板**等
  - **研类**：调研 / 竞品 / 政策等（1.0 已具备）
  - **数类**：上传表格后分析并给出结论 / **图表说明**（建议图型、坐标或分组含义、读图结论；**不**引入真实画图引擎）
  - **表格入口**：①「资料库」可上传 CSV/Excel，并「用此表分析」；②「新建」选表格分析后，生成计划前即可上传或从资料库选表（不必先进任务页再传）
- **不做（本阶段明确）**：企业版、多人协作、正式组织权限；浏览器操控、视频/网页搭建、钉钉/企微深度 IM 集成等「对齐大厂全家桶」项暂不追。
- **可讨论（未立项）**：个人桌面客户端（决策 4B）；上云仍按 1.0 暂缓。

## 2. 输入、过程和产物

**入口（三者都要，分期做深）**

1. **场景卡片**：首页一眼可点的场景，点完带出模板提示，少想提示词。  
   当前场景：竞品调研、会议纪要、周报总结、**邮件稿**、**方案模板**、表格分析。
2. **能力货架**：技能 / 专家可逛、可搜、可点选（新建页「能力货架」）；不再只藏在下拉里。
3. **自由输入 + 自动识别**：一句话时尽量判断是周报、邮件、方案还是调研等，减少选错场景。

- 过程：仍保留「计划 → 确认 → 执行 → 可重试/改计划」；高风险外发仍须确认。
- 可选输入：用户自填的公开网页链接（最多 3 个），执行时可能抓取正文；不是全网自动扒，也不是本地上传。

**产物**

- 继续：页面预览 + Markdown / Word / Excel / PPT / 飞书导出（按任务类型选用）。
- 强化方向（决策 5AB）：**同一任务尽量能出多种交差形态**（文稿为主，表格/PPT 按场景加强），不强制每个场景一上来就三种都满分。
- 表格场景提示引导「分析 + 图表说明」。
- 表格文件可先进入「资料库」（本机授权文件夹），也可在新建页直接准备后再生成计划。
- **资料库不做报告落盘**：任务报告用页面下载（Markdown / Word / Excel / PPT）或飞书导出；可反复下载，不写入资料库。
- 资料库列表默认「仅表格」、可搜文件名、按最近修改排序；历史 `report.*` 成品不展示。
- 顶栏「资料库」≠ 新建页输入框：输入框是下任务的地方；资料库是放原料/参考文件的地方。

## 3. Agent 主链路

与 1.0 相同骨架：计划确认门 + 工具执行 + 成品落盘。  
扩面后按**场景模板**切换默认计划大纲与输出结构（写类 / 研类 / 数类），而不是各写一套互不兼容的引擎。

## 4. 什么算生成得好（扩面）

- 写类：结构对口（如周报有进展/问题/下周；纪要有决议与待办），像能直接转发的草稿。
  - **邮件**：有建议主题 + 可粘贴正文。
  - **方案**：背景 / 目标 / 方案 / 实施 / 风险骨架齐全。
- 研类：沿用 1.0（有结构、有来源纪律、不编造）。
- 数类：结论能对应到上传表里的字段/汇总；算不清就标明待核实，不编数字；成稿须含「图表说明」一节。
- 效果数字标准：已由 1.17 样例打分固化——五维平均 ≥2 且无「不能接受」（见 `docs/项目状态.md` D2/D3）。

## 5. 交付阶段与优先级

| 迭代 | 内容 | 状态 |
| --- | --- | --- |
| **1.1（本版）** | 首页场景卡（竞品调研、会议纪要、周报、**邮件稿、方案模板**、表格分析）+ 自由输入识别 + 技能/专家入口加强 + CSV/Excel 上传分析（成稿含**图表说明**）+ 导出复用 | **已验收** |
| **其后（本刀：货架逛搜）** | 新建页能力货架为独立模块：专家/技能可浏览、可搜索、点选带入（擅长/适合/成品）；参考公开网页链接可选 | **已通过** |
| **其后（更多专家包）** | 新增政策速读 / 对客话术 / 项目推进（场景卡 + 技能 + 专家） | **已通过** |
| **其后（多形态打磨）** | 按 skill 推荐下载格式（表格→Excel，写类→Word，研类→Markdown） | **已通过** |
| **其后（任务合并）** | 侧栏多选合并；主任务下展开查看被并入项 | **已通过** |
| **其后讨论** | 个人桌面端；更多连接器；上云 | **个人桌面端已立项（1.9）**；连接器/上云仍单独立项 |

**截止时间**：无对外硬截止；以本人本地能稳定交差为准。

## 6～8. 模型 / 数据 / 上线

沿用 1.0：自备 Key、本机存储、费用软闸门、暂不上云、单人本机。

## 一句话（1.1）

> 本机 AI 办公搭子：用场景卡片或一句话下任务，自动识别意图、拆步骤执行，交付能交差的周报/纪要/邮件/方案/调研/表格分析（含图表说明）——对标 WorkBuddy 的「可执行可交付」，不追齐腾讯/钉钉全家桶。
