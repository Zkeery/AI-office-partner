## 1. 目标用户与核心任务

- **谁**：个人职场人（先自用验证）。
- **场景**：接到调研 / 汇报类任务，需要尽快交出像样的书面成品。
- **核心任务**：用自然语言下任务，系统自己拆步骤、检索与整理，产出**可下载的调研报告**，而不只是聊天建议。
- **现状凑合方式（默认示例，可后续换成真实卡点）**：老板要调研报告 → 自己搜资料 → 粘贴进 Word → 改格式，耗时长、难交差。

## 2. 输入、过程和产物

**输入**

- 主输入：一句话 / 一段文字描述任务。
- 可选：1～3 个参考链接，和/或 1～3 个参考文件（如已有笔记、竞品材料）。

**过程中用户要看到 / 确认什么**

1. 系统给出**任务计划**（步骤清单）。
2. 用户确认后才开始执行；执行中可暂停。
3. 执行过程可见进度与关键中间结果（检索摘要、大纲等）。
4. 失败时给出人话说明，保留已完成步骤，支持重试或改计划再跑。

**产物**

- 第一版：页面可读的调研报告 + **下载 Markdown**。
- 紧随小增量：下载 Word（不挡第一版验收）。
- 后置：表格、PPT、腾讯文档等。

**长期保留**

- 本机保存任务历史、计划、产物与关键中间结果，进程重启可恢复。

## 3. Agent 的主链路

1. 用户描述任务（可附链接 / 文件）。
2. Agent 生成计划 → **用户确认**。
3. 按计划自动执行：联网检索、阅读上传材料、整理要点、起草报告。
4. 产出报告；用户可要求局部重写或改计划续跑。
5. **对外发送**（邮件 / 分享等）若未来接入：必须再次人工确认。第一版可不实现发送，但红线预留。

**必须用户确认才能继续**

- 开始执行计划。
- 任何对外发送（若已实现）。

**默认可自动**

- 读网页 / 检索、读用户上传材料、写本机草稿与报告文件。

## 4. 什么算「生成得好」

用产品语言（第一版，数字标准待样例打分）：

- 报告有清晰结构（背景 / 要点 / 结论或建议）。
- 关键结论尽量带来源（链接或材料出处）；**不允许编造无来源事实**。
- 联网检索不足时：**不得**用模型常识冒充事实；应写明「未找到公开来源」或标「待核实」，结论可留空。
- 读起来像「能交差的草稿」，不是聊天口水话。
- 允许：个别排版不完美、次要细节不全。
- 谁判断：产品经理本人；第一次真实冒烟时用 5～10 条真实任务打分后固化标准（记为「待样例打分」）。

## 5. 交付阶段与优先级

| 优先级 | 内容 |
| --- | --- |
| **MVP（第一版必须）** | 自然语言下任务 → 计划确认 → 联网检索 + 参考材料 → 页面阅读 + Markdown 下载；失败可重试/改计划；本机持久化。连接器仅含「联网检索」这一个插头，不展开商店式连接器体系 |
| **紧随** | Word 下载；授权本地文件夹读写；**技能**（可复用办事套路，如「竞品调研」）；**专家**（人设 + 技能包的薄封装，与技能同批，不单独开大工程） |
| **后置** | **更多连接器**（网盘、邮箱、腾讯文档等）；**定时任务**（到点自动跑计划并出成品）；表格 / PPT；腾讯办公生态；桌面端 + App；多人协作 / 正式上云账号体系 |
| **截止时间** | 无硬性对外截止；先追求本人本地能稳定交差 |

### 5.1 后续能力说明（愿望清单，非 MVP）

| 能力 | 大白话 | 排期理由 |
| --- | --- | --- |
| 技能 | 把跑通的流程固化成可一键调用的套路 | 主链路（计划→执行→报告）稳定后才有可固化的流程 |
| 专家 | 带角色的专用搭子，本质是人设 + 技能包 | 与技能一起做，避免两套体系 |
| 连接器 | 接到外部系统的插头 | MVP 只做检索；其余插头等报告主线交差后再扩 |
| 定时任务 | 到点自动执行（如每周行业速览） | 依赖「手动下任务已能稳定交差」之后再上 |

## 6. 模型与成本约束

- 用户**自备 API Key**，不锁定单一厂商。
- 任务正文与上传材料**允许**发给当前配置的云端模型做推理（界面须告知）；本产品不拿这些数据做训练。
- 单次任务执行前应能看到**成本量级提示**；预估超过约 **¥5** 时须二次确认是否继续。
- 月费用上限：本地自用阶段不定死，靠控用量；上云前再定。
- 指定/禁用厂商：无。

## 7. 数据与非功能要求

- 任务内容、上传材料、报告可能含个人或公司信息 → 本产品**不当训练数据**；日志不记密钥与完整敏感正文。
- 数据先放**本机**；不要求出境；上云后数据驻留策略再定。
- 用户量：先 1 人自用。
- 响应：计划目标 ≤30 秒给出；完整报告允许数分钟级，异步进度可见。
- 上传参考文件：`.md` / `.txt` / `.markdown` / `.pdf` / `.docx`；单文件 ≤20 MB；最多 3 个。
- 联网检索：开放公网；MVP 不登录用户私人账号。
- 红线：不编造无来源结论；检索不足不写假事实；不擅自对外发送；不删除用户未授权文件；上传材料不用于训练。

## 8. 上线与账号（后填 / 已定方向）

- 先**本地自用**，暂不上云、暂不对外。
- 登录：MVP 单人本机使用，不做正式账号体系。
- 企业认证 / 云费用预算：暂缓，上云前再办、再填。

## 一句话产品定义

> 给个人职场人用的本地 AI 办公搭子：你用自然语言下调研任务，它先出计划等你点头，再联网检索并整理成可下载的 Markdown 调研报告——能交差，不只是聊天。
