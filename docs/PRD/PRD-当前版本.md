# AI办公搭子 · 当前需求与实现范围

更新：2026-10-04。本文汇总产品 1.0、1.1、阶段 1.25 及本轮界面、模型和真实工作流要求；旧 PRD 保留各阶段当时的范围。当前交付状态见[项目状态](../项目状态.md)，协议见[API 接口](../API接口.md)。

## 用户与目标

个人职场人、本机单用户使用。用户用自然语言或场景入口提交任务、选择模型并添加材料，获得可以阅读、修改、追溯和下载的办公成果。覆盖写作、调研、表格分析；提供技能/专家、资料库和自动化。

## 真实入口与视觉要求

- `/` 为正式工作台，`/design-lab/fusion` 与 `/design-lab/lilac` 兼容旧链接，三者复用同一套真实业务状态与接口。
- 主背景与侧栏统一奶白 `#fffdf9`，内容用白色，功能图标使用紫、蓝、绿、暖金色；保持专业、清楚与适度亲切。
- 输入框参考用户提供的 Codex 截图：附件与模型在左，圆形紫色发送按钮在右；Enter 提交、Shift+Enter 换行，输入法候选确认不触发提交。
- 首页任务、成果、执行状态和自动化数量来自真实接口。空数据展示空状态，加载时展示加载状态；不得用固定示例数字或假报告替代。
- 原四方向比较页 `/design-lab` 仅保留设计研究示例，不作为业务入口。
- 语音图标明确表示尚未接入；不录音、不宣称支持语音识别。

## 输入与模型选择

- 新任务与新自动化必须由用户显式选择模型，新草稿不预选。首批支持 DeepSeek、GPT、通义千问、豆包的服务端接入；用户菜单仅展示已配置可用项。
- 规划、执行、重试、报告改写和自动化跑次沿用任务保存的厂商与具体型号，不静默切换厂商或退回模拟。
- 任务文本必填；参考链接最多 3 个；上传材料支持 TXT、Markdown、PDF、DOCX、CSV、XLSX，单文件不超过 20 MB，每任务最多 3 份材料。
- 新建时可直接添加真实文件；表格会进入完整计算链路。上传完成后重新规划，再确认执行，防止计划遗漏材料。
- 文件、模型和任务数据均使用本项目配置，不借用其他项目凭据。模型目录的可用标记表示配置完整，实际调用仍可能因厂商权限或网络失败。

## 执行与结果

- 延续简洁交付模式：点击发送后创建计划、补充材料并自动发起执行；超过费用软阈值时停下等待用户明确确认。
- 用户可查看计划、步骤、执行依据、失败原因，暂停、继续或修改计划。未知工具不能显示成功；可选读取没有输入时须标明跳过原因。
- 调研结论须遵循来源纪律。缺少来源时标明待核实，不用模型常识伪装已检索事实。
- 报告、任务、版本和分析快照保存在本机。任务地址包含任务 ID，刷新后恢复同一任务；服务重启时原运行任务转为可继续的暂停状态。
- 搜索覆盖任务标题、用户输入与报告正文；保留任务合并、归档与恢复。快速切换搜索和面板时，过期响应不得覆盖较新的结果。

## 表格、图表与多格式交付

- CSV/XLSX 在明确容量内读取全部有效数据行和全部工作表（包括隐藏表）。每次分析上限：100,000 行、1,000,000 数据单元格、50 张表、每表 512 列。
- 程序计算汇总、分组、月度环比/同比与异常，模型解释计算结果。超限或公式缺少缓存结果时明确失败，不将抽样或零值冒充完整结果。
- 数值计算排除空值和非法数字，离群值保留；比例/单价按未加权均值处理。每表选择一个主要指标；柱图展示前 12 个分组、折线展示最近 24 个有数据月份，异常样例最多 100 条并给出总数。
- Markdown、Word、Excel、PPT 可实际下载。表格分析的 Excel 包含明细、复算公式和原生图表，PPT 可含可编辑图表及分页正文；修改 Excel 明细不会自动刷新已经生成的报告。

## 报告修改与版本

- 支持全文或指定章节改写，章节之外保留原文；生成、改写、合并、恢复都留版本。
- 可查看旧版全文和差异，恢复另存新版本；用预期版本号防止覆盖别人或另一标签页刚保存的修改。
- 历史报告首次读取或修改时建立版本记录。恢复后的导出使用该版本所对应的数据快照。

## 资料库、自动化与飞书

- 资料库用于原料与参考文件，支持浏览、筛选、读取和表格上传；用户明确选择后才将资料加入任务，不自动注入整个目录。
- 自动化保留定时、自定义间隔、上游自动化成功后触发、立即执行、启停、跑次历史和站内结果通知。新建自动化必须指定模型。
- 用户可连接/断开自己的飞书账号，并主动将报告导出到「我的」云文档。
- 普通用户界面不显示系统接入、Webhook 密钥/轮换、群通知配置、开放平台回调地址或应用身份导出入口。管理员接入方式保留在维护文档与服务端能力中。
- 群通知保持默认关闭，真发仍暂缓；本轮没有自动对外发送、创建新通知规则或更改既有配置。

## 当前验收与未实现范围

此前后端 126 项测试通过，包含全量表格、版本冲突和模型路由；本轮前端构建、类型与 Lint 通过。真实 DeepSeek 已从新版入口完成上传、执行、分析、报告和三种 Office 文件下载，并验证刷新恢复、搜索及手机端；证据见[真实工作流接通](../evidence/真实工作流接通/验收说明.md)。

开发检查不等于用户已确认视觉或产品验收。当前仍是本机单用户应用；没有新增服务端角色鉴权、企业多人隔离、通用浏览器 Agent、插件市场、语音识别或公网部署。GPT、通义千问、豆包尚无本项目真实调用验收，配置状态见[模型接入与选择](../模型接入与选择.md)。
