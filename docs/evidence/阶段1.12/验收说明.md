# 阶段 1.12 验收说明｜导出与报告体验

## 照着点

1. 打开 http://127.0.0.1:3040 ，新建并跑完一条周报/调研/表格任务
2. 右侧「成品报告」应看到主按钮「下载·Word/Excel/Markdown」（按场景）
3. 点「复制正文」→ 粘贴到备忘录应看到报告文字
4. 点主下载 → 文件名应带任务标题，不是一律 `report.docx`
5. 点「更多导出」→ 其余格式与「改写报告」仍在
