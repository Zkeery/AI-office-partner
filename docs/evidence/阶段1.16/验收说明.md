# 阶段 1.16 验收说明｜交付体验小打磨

> 产品经理点验（2026-09-29）：识别免点应用、搜归档可见「恢复到列表」通过；要求 commit。

## 照着点

1. 打开 http://127.0.0.1:3040 → 新建  
   - 默认应能看到「写稿」下的场景（周报、发言稿等）
2. 在输入框打：`帮我写一份周报`  
   - 应出现「已按「周报总结」准备（可直接开始）」  
   - **不要**再点应用，直接点「开始生成」
3. 侧栏搜关键词（如「周报」）→ 点带「归档」标记的任务 → 应有「恢复到列表」
4. 点「删除」→ 应先弹出确认
