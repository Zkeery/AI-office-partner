# 销售额全量分析报告

## 一、背景与数据范围

本报告基于文件 **合成销售数据.xlsx**，共 2 个工作表、62 行数据：

| 工作表 | 数据行数 | 说明 |
|---|---|---|
| 销售明细 | 60 | 含区域、产品、月份、销售额、订单量、转化率等维度 |
| 线下补充 | 2 | 仅含区域与销售额，维度较少 |

**统计口径**：销售额、订单量按求和汇总；转化率为**未加权均值**（各记录等权平均），不代表按订单量或销售额加权的整体转化率。环比、同比在缺少基期或基期为 0 时记为「—（缺少可用基期）」。全部数据无缺失、无非法值、无离群值，程序标记异常总数为 0。

## 四、异常与待核实

1. **无程序标记异常**：异常总数 0，离群值 0，缺失与非数字均为 0。
2. **同比/环比缺失属正常**：2025-01 无前期与上年同期；2026-02 无 2025-02 基期，非数据错误。
3. **订单量与转化率完全不变**：三个期间订单量恒为 210.0、转化率未加权均值恒为 20.5%，而销售额翻倍增长。此现象**待核实**——可能为合成数据设定，也可能与单价变化有关，但当前结果未提供单价指标，不作因果推断。
4. **两工作表口径是否可合并待核实**：销售明细（60 行）与线下补充（2 行）列数不同，区域不重叠（华南/华东 对 华北），是否属同一业务口径**未找到公开来源**。
5. **转化率均值口径提示**：20.5% 为未加权均值，若各记录订单量差异大，加权后结果可能不同，本报告不将其表述为整体转化率。

## 五、建议

1. **补齐基期数据**：补充 2025-02 等缺失期间，以计算 2026-02 同比，完善月度对比。
2. **核实订单量与转化率不变的原因**：确认是否为数据生成设定；如为真实业务，需排查订单量与销售额背离的驱动因素。
3. **明确两表合并口径**：确认线下补充表是否纳入整体区域汇总，避免区域口径混淆。
