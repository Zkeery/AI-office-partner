## 异常与待核实

1. **无程序标记异常**：异常总数 0，各指标离群值 0，缺失与非数字均为 0。
2. **同比/环比 null 属正常缺失**：2025-01 无前期与上年同期；2026-02 无 2025-02 基期。非数据错误。
3. **订单量与转化率完全不变**：三个期间订单量恒为 210.0、转化率未加权均值恒为 0.205，而销售额翻倍增长。此现象**待核实**——可能为合成数据设定，也可能反映单价变化，但当前结果未提供单价指标，无法判断原因，不作因果推断。
4. **两工作表口径是否可合并待核实**：销售明细（60 行）与线下补充（2 行）列数不同（7 列 vs 3 列），区域不重叠（华南/华东 vs 华北），是否属同一业务口径**未找到公开来源**。
5. **转化率均值口径提示**：0.205 为未加权均值，若各记录订单量差异大，加权后结果可能不同，本报告不将其表述为整体转化率。

## 建议动作

1. **补充基期数据**：补齐 2025-02 等缺失期间，以计算 2026-02 同比。
2. **核实订单量/转化率不变的原因**：确认是否为数据生成设定；如为真实业务，需排查订单量与销售额背离的驱动因素（如客单价）。
3. **明确两表合并口径**：确认线下补充表是否纳入整体区域汇总，避免区域口径混淆。
4. **补充单价/加权指标**：如需评估整体转化率，应提供按订单量或销售额加权的口径。
5. **保留明细与公式**：完整明细、公式与图表见 Excel 导出文件，本报告仅压缩展示已计算结果。
