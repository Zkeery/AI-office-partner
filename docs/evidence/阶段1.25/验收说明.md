## 章节修改、版本与持久化

1. 浏览器修改 v1 的「建议动作」，生成 v2；程序比较确认该节以外的正文逐字不变。
2. 浏览器打开版本记录和差异，将 v1 恢复为 v3；程序确认 v3 与 v1 全文一致，v2 仍可读取。
3. 重启后端后再次读取版本与数据，内容保留。随后验证全文改写生成 v4，再对图表解读做局部修改生成 v5。
4. 最终再次重启服务，v1～v5 和 62 行分析快照仍可读取。
