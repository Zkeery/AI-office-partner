# 第 7 阶段技术开发文档｜PPT 导出

> PRD 后置产物：报告可下载 `.pptx`，按标题拆成幻灯片，便于汇报。  
> **不做**：复杂动画、主题商店、腾讯文档同步、自动配图。

## 一、目标
- 已完成任务可下载 PPT
- 可选写入授权工作区（`report.pptx`）
- Markdown：首个一级标题作封面；每个二级标题开新页；要点/正文落入当前页

## 二、依赖
- `python-pptx`
- 无新密钥、无新端口

## 三、API
- `GET /api/tasks/{id}/report.pptx`
- 工作区 `formats` 增加 `pptx`

## 四、转换规则
| Markdown | PPT |
| --- | --- |
| 第一个 `#` | 封面标题页 |
| 每个 `##` | 新一页，标题=该行 |
| `###` / 列表 / 正文 | 当前页正文条目 |

## 五、验收
成功任务 →「下载 PPT」→ PowerPoint/Keynote/WPS 能打开，至少封面 + 内容页。
