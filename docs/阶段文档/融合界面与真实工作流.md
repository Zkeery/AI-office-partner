## 接通内容

- 首页展示实际任务、成果和自动化数量；点击卡片进入相应任务，空结果和加载状态如实显示。
- 输入框上传真实材料、手动选择模型并创建任务；有材料时上传后重新规划，再发起执行。成功后清空草稿及模型选择。
- 复用现有报告、图表、章节改写、版本、恢复、Office 下载和个人飞书导出逻辑。
- 任务列表保留服务端搜索、合并、归档入口；资料库和自动化切换到实际面板。手机抽屉导航可操作。
- 任务 ID 与面板写入 URL，刷新恢复同一任务；列表中找不到所选任务时按 ID 读取详情。用请求序号忽略过期搜索/报告响应。
- 文件不会因输入文字或切换场景被自动丢弃；材料类型、大小和数量在前端提示，后端继续校验。

## 模型与用户界面边界

新任务/自动化必须显式选择模型，保存具体型号；可用菜单和服务端配置约定见[模型接入与选择](../模型接入与选择.md)。当前真实验收使用 DeepSeek，另外三家尚待配置。

保留个人账号连接、任务、资料库和自动化等日常操作。移除管理员接入、Webhook 密钥/轮换、飞书群配置、回调登记和应用身份导出入口；后端相关接口仍存在，未新增角色鉴权。语音图标明确未接入，不假装启动录音。没有改动既有群通知或创建新的通知规则。
