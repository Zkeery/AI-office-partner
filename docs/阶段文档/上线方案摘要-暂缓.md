# 上线方案摘要（暂缓）

更新：2026-10-04。当前仍在本机自用，没有公网部署。本轮完成真实融合工作台、模型选择、完整表格与版本管理，未增加云资源或账号体系。

## 本机运行

前端 `http://127.0.0.1:3040/`，后端 `http://127.0.0.1:8040`；启动、生产构建与重启见 [README](../../README.md)，排查方法见[使用与故障排查](../使用与故障排查.md)。任务、文件、报告版本和 OAuth 状态留在本项目运行数据目录。

`/design-lab/fusion` 与 `/design-lab/lilac` 已兼容真实工作台；四方向比较页 `/design-lab` 仍是设计研究用途。页面能访问不等于完整业务可用，实际验收需要完成创建、执行、报告和下载。

## 后续上云需另行决定

目前没有正式登录、多租户数据隔离、服务端角色权限或托管的持久化/备份。隐藏管理员界面入口没有改变这些范围。后端依赖本机 SQLite 与文件目录，不能只把前端上传到静态托管就认为整个产品完成部署。

用户明确提出上云后，再选择平台、确认数据存储与备份、账号和访问权限、模型/飞书凭据、预算及部署验收。此前文档中的云服务价格与工期估计不作为当前报价或承诺，届时以选定方案和实测为准。
