# 上线方案摘要（暂缓）

> 日期：2026-09-28  
> 依据：PRD 第 8 节「先本地自用，暂不上云、暂不对外」；部署手册默认火山引擎 veFaaS。

## 结论
**当前不上云。** 本地 MVP（第 1–12 阶段）+ 真实飞书导出已可用。公网部署等你明确要给外人用、并确认预算后再开。

## 若以后上云（推荐默认）
| 项 | 推荐 |
| --- | --- |
| 跑程序 | 火山引擎函数服务 veFaaS |
| 网址 | 函数服务 + API 网关（自带 HTTPS） |
| 数据 | 个人认证过渡：预留实例 + SQLite 定期备份；企业认证后切 RDS PostgreSQL |
| 文件 | 对象存储 TOS |
| 登录 | 邀请码（PRD 暂不做正式账号体系） |
| 费用量级 | 个人试用档通常为每月数十元级（函数+网关）；RDS/正式流量另计，开工前再核价 |
| 耗时 | 有认证与密钥后，约 0.5～2 天可完成首版部署与验收 |

## 上云前你需要准备
1. 云平台账号与实名（个人 / 企业）  
2. AccessKey（只填控制台 / 本地密钥文件，不要发到聊天）  
3. 确认预算上限（记入决策台账 D9）  
4. 线上环境变量：模型 Key、飞书凭证、`FEISHU_MOCK=0` 等

## 不上云时怎么用
照 README 在本机启动：前端 http://127.0.0.1:3040 ，后端 http://127.0.0.1:8040 。
