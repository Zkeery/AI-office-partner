# 第 1.3 阶段技术开发文档｜货架逛搜

> 配套：`docs/PRD/PRD-1.1.md`、通用技术栈手册、前端技术栈手册。  
> 只覆盖货架逛搜；不提前做多形态打磨。  
> 状态：**已实现并验收通过**（2026-09-28）。

## 一、阶段目标
- 交付：新建页「能力货架」为**独立模块**（与场景卡不同级）；可打开面板浏览专家/技能；可搜索；每条展示擅长 / 适合 / 成品；点选带入任务。
- 产物：前端货架 UI；目录字段 `strength` / `best_for` / `output_shape`；公开网页链接保留并写清用途。
- 验收：见第十一节。
- 不做：新专家内容扩面（归 1.4）；按场景默认下载格式（归 1.5）；桌面端/企业版。

## 二、技术适配摘要
- 沿用既有 Next.js 正式前端 + FastAPI 目录 API；不新建引擎。
- 开发路径：纵向切片（前端货架 + 已有 `GET /api/skills` `/api/experts`）。

## 三、技术栈与模型
- 前端：Next.js、TypeScript、Tailwind、CSS 变量主题。
- 后端：既有 catalog JSON；mock/真实模型不变。

## 四、环境与配置
- 端口：前端 3040，后端 8040；无新增密钥项。

## 五、项目结构
- `frontend/app/page.tsx`：货架模块与弹层
- `frontend/app/globals.css`：货架与主题
- `backend/app/catalog/skills.json` / `experts.json`：补齐展示字段
- `frontend/lib/api.ts`：类型扩展

## 六、数据与状态
- 无新表；选型状态仅前端本地（`expertId` / `skillId`），创建任务时写入任务字段。

## 七、API
- 复用 `GET /api/skills`、`GET /api/experts`；响应可含 `strength`/`best_for`/`output_shape`。
- 公开网页链接仍走创建任务 `urls`（最多 3 个）；非上传、非全网自动扒。

## 八、Prompt
- 无新 Prompt；专家/技能仍通过既有计划生成链路注入。

## 九、界面切片
- 正式产品切片：新建页场景卡下方独立「能力货架」卡片 →「打开货架」弹层。
- 参考链接入口文案改为「补充公开网页链接（可选）」。

## 十、测试
- mock：既有 catalog / 场景测试保持通过。
- 人工：打开货架可见全部条目与三行说明；搜索有效；点选后「已选」展示。

## 十一、验收清单
- [x] 场景卡与货架不同级展示
- [x] 货架可搜、可点选、有擅长/适合/成品
- [x] 链接说明可读懂

## 十二、风险
- 目录变多后弹层需可滚动；已做 `max-height` 滚动。

## 十三、交接
- 下阶段可直接往 catalog 加专家/技能并自动出现在货架。
