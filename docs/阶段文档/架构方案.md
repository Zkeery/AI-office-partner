# AI办公搭子 · 当前架构方案

更新：2026-10-04。依据[当前 PRD](../PRD/PRD-当前版本.md)、[项目状态](../项目状态.md)、现行代码与本轮浏览器验收。2026-09-27 的阶段 1 方案已演进至下述结构；没有重新运行共享蓝图模型管线。

## 运行形态

本机单用户应用：Next.js 14 / React 18 前端在 3040，FastAPI / SQLAlchemy 后端在 8040，SQLite 和文件位于本项目运行数据目录。可选 Electron 只是本机 Web 的窗口，不提供独立业务实现。正式公网部署与多用户权限仍未实现。

## 页面与业务组织

- `frontend/app/page.tsx` 管理真实任务、输入、上传、执行、资料库、自动化、搜索和导出状态。
- `components/FusionWorkspace.tsx` 提供奶白侧栏、响应式导航、Codex 风格输入框和真实成果卡片；通过业务回调操作相同状态，不在视觉页内维护示例任务。
- `/design-lab/fusion` 和 `/design-lab/lilac` 复用正式页面，刷新任务地址可以恢复所选任务。`/design-lab` 保留为独立设计比较页。
- `ModelPicker` 从公开模型目录读取选项，仅显示可用配置。新任务和新自动化没有预选，服务端同时校验必填模型。
- `ReportWorkbench` 显示计算图表、章节改写、版本列表、差异与恢复。首页数据和进度来自真实任务；没有报告时显示空状态。
- 请求序号防止过期列表/搜索/报告响应覆盖新结果。正在运行的任务按秒轮询；服务端保留 SSE 事件接口。

## 创建到交付的数据流

1. 用户填写任务、选择模型，添加最多三份材料或参考链接。
2. `POST /api/tasks` 创建任务并生成计划，将具体模型型号写入任务元数据。
3. 前端上传材料或挂载选定的资料库文件；有材料时重新规划，确保计划覆盖实际输入。
4. 前端调用确认执行接口，后端检查状态和费用闸门后启动异步任务；费用超限等待用户确认。
5. 运行器依计划执行工具。每步保存状态与结果依据，未知工具报错，没有输入的可选读取记录跳过。
6. 表格由程序读取全部数据并计算，分析快照写入任务产物；模型使用真实计算结果撰写正文。
7. 报告与版本保存后，前端显示成稿、图表及下载/改写入口。Office 导出从对应正文和快照生成实际文件。

## 服务模块

| 模块 | 主要职责 |
| --- | --- |
| `api/tasks.py`、`services/tasks.py` | 创建、规划、异步运行、暂停、重试、材料、合并、归档及导出 |
| `services/models.py`、`services/llm.py` | 配置目录、厂商与具体型号解析、兼容 Chat Completions 请求 |
| `services/table_analysis.py` | CSV/XLSX 全量读取、容量检查、指标/分组/月度/异常与图表数据 |
| `services/reports.py` | 章节、不可变版本记录、差异、恢复及乐观并发检查 |
| `services/xlsx_export.py`、`pptx_export.py` | 原始明细、复算公式、原生图表与分页导出 |
| `api/schedules.py`、`services/schedules.py` | 定时/依赖/手动触发、模型继承、跑次和通知 |
| workspace、Feishu 相关模块 | 显式参考材料、个人 OAuth 导出；维护接口另行保留 |

模型选择不会修改共享 Settings。新任务固定型号，后续规划、执行、重试和改写沿用；密钥和端点仍从服务端配置读取。历史任务保留兼容路径，不能反推并伪填其实际型号。

## 持久化与状态

SQLite 保存任务、步骤、事件、报告版本、自动化和跑次。上传与报告/分析快照保存到本机文件目录；OAuth token 和通知偏好也只在运行数据目录，均不入 Git。启动应位于 `backend/`，以保持相对 `DATA_DIR=./data` 的位置稳定。

常规状态为 `planning → plan_ready → running → succeeded`，执行中可暂停或失败；重启时尚在运行的任务转为 `paused` 等待继续，已保存数据保留。归档和合并是附加状态。

报告版本以递增序号记录；改写/恢复检查 `expected_version`，冲突返回 409。恢复生成新版本并沿用目标版本的数据快照，不覆盖旧记录。已有数据库通过初始化迁移补充模型字段和报告版本结构，不删除原任务库。

## 计算与集成边界

每次表格分析最多 100,000 行、1,000,000 数据单元格、50 表、每表 512 列；缺公式缓存时明确失败，不运行上传宏或公式。比例和单价使用未加权均值；展示图表可截取分组/月度窗口，Excel 保留完整结果与明细。

普通用户界面保留个人飞书授权与主动导出，移除 Webhook 密钥、群通知配置、回调登记和应用身份导出入口。相关后端实现仍存在，当前没有多用户登录或后端角色隔离。群通知默认关闭，真发暂缓。

完整接口见[API 接口](../API接口.md)，配置见[模型接入与选择](../模型接入与选择.md)，限制与故障处理见[使用说明](../使用与故障排查.md)。
