更新：2026-10-04。本文同步已经实现的技术适配，不再使用阶段 1 的待开工清单。需求见[当前 PRD](../PRD/PRD-当前版本.md)，模块细节见[架构方案](架构方案.md)。

## 产品与交互

面向个人本地办公，涵盖调研、写作、数据分析及多格式交付。采用同一任务引擎，按场景、技能与专家调整规划和产物。用户显式选择模型、添加材料并发送，前端自动接续计划与执行，费用超限保留确认；结果支持追溯、修改与版本恢复。

奶白融合界面已复用正式业务逻辑，包含手机抽屉导航、附件、参考链接、模型选择、真实成果、任务搜索、资料库及自动化。语音识别未接入。

## 适配边界

- 不新增云基础设施、跨项目凭据或共享数据存储。当前仍是本机单用户。
- 保留费用软闸门、输入和模型输出校验、真实工具结果、持久化与版本冲突保护。
- 普通用户界面不提供管理员配置；此调整没有新增服务端角色鉴权，也不表示已经具备公网多用户隔离。
- 不引入通用浏览器 Agent、多 Agent 团队、RAG 向量库、通用插件商店或语音识别。
- 不重跑未配置的蓝图模型管线；2026-09-27 的手册分析来源保留为历史事实，未将其写作独立模型审核。
- GPT、通义千问和豆包的接口路由已测试，但缺少本项目实际凭据，未宣称真实接通。型号、端点与兼容条件见[模型文档](../模型接入与选择.md)。
