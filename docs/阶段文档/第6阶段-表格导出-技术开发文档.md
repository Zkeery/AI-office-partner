# 第 6 阶段技术开发文档｜表格（Excel）导出

> PRD 后置产物优先落地：报告可下载 `.xlsx`，结构清晰、可再编辑。  
> **不做**：复杂透视表、多 Sheet 数据分析、PPT、腾讯文档同步。

## 一、目标
- 已完成任务可下载 Excel（`report.xlsx`）
- 可选一并写入授权工作区
- Markdown 标题 / 列表 / 段落落到「类型 + 内容」两列，便于筛选与编辑

## 二、依赖
- `openpyxl`（写入 xlsx）
- 无新密钥、无新端口

## 三、API
- `GET /api/tasks/{id}/report.xlsx` → 文件流；报告未就绪返回 `REPORT_NOT_READY`
- 工作区导出 `formats` 增加 `xlsx`

## 四、转换规则
| Markdown | Excel「类型」列 | 「内容」列 |
| --- | --- | --- |
| `#` / `##` / `###` | 标题1/2/3 | 标题文本 |
| `-` / `*` / `1.` | 要点 | 条目文本 |
| 其它非空行 | 正文 | 原文 |

## 五、界面
报告预览区增加「下载 Excel」；导出到工作区时默认含 md / docx / xlsx。

## 六、测试
无报告 → 404；跑通后 → 200 且为 zip/xlsx 魔数；工作区可写出 `report.xlsx`。

## 七、验收
打开已成功任务 → 下载 Excel → 用表格软件打开能看到标题与正文分行。
