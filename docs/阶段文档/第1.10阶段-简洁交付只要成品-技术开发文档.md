# 第 1.10 阶段技术开发文档｜简洁交付（只要成品）

> 产品反馈：选好场景/下任务后，用户不必看计划与中间步骤；只要最终报告并可导出。  
> 状态：**已开发，待产品经理点验**（2026-09-28）。

- 交付：新建任务后**自动开始生成**；默认界面突出「生成中 / 成品报告 + 导出」；计划与步骤收进可展开的「过程详情」。
- 不做：删掉后端计划能力；不做桌面安装包；费用超软上限仍须确认。

## 二、改动
- `frontend/app/page.tsx`：创建后自动 `confirm`；文案与主按钮改为交付导向；过程折叠。
- 无后端契约破坏（仍走计划→执行）。

## 三、验收
- [ ] 新建周报/调研后无需点「确认执行计划」即可进入生成（费用超限除外）

- [ ] 成功后第一眼是报告与导出
