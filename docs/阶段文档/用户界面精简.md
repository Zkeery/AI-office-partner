# 用户界面精简

更新：2026-10-05。用户要求办公界面以节约时间、提高效率为目标，删除普通流程中的 Token 预算及不必要的管理员配置。本轮取代现行文档中要求用户选择模型、技能、专家与预算的旧展示约定，原验收证据保留历史事实。

## 用户流程

普通任务：描述要完成的工作 → 添加材料或参考链接 → 开始处理 → 查看、修改或下载结果。

自动化：填写名称和工作内容 → 设置执行时间 → 保存。材料与参考链接通过可选入口添加；预设时间不显示分钟输入，仅自定义时展开。用户不必理解模型、Token、技能、专家和内部执行策略。

| 页面 | 保留给用户 | 移到管理页或服务端处理 |
| --- | --- | --- |
| 工作台 | 任务输入、材料、链接、业务场景快捷入口、最近成果 | 模型选择、能力货架、专家技能、未接入语音占位、模型型号 |
| 任务结果 | 需求、进度、成果、依据、改写、版本、下载和主动导出 | 调用次数、Token 用量、未知/模拟调用统计、内部标识 |
| 自动化 | 内容、时间、材料、状态、编辑、启停和结果历史 | 模型、预算、专家技能、依赖触发配置、材料读取策略和运行统计 |
| 资料库 | 浏览、上传、选择材料 | 服务器根目录与授权目录设置 |

## 系统处理

省略模型时，服务端从管理员已有 `LLM_*` 配置解析默认模型并保存实际厂商与型号；不从可用列表随机选择，不在真实模式静默使用模拟。无法解析时返回配置错误。省略技能和专家时复用现有场景判断；内部显式覆盖仍兼容。

自动化采用现有内部默认上限 50,000。旧 API 显式上限和历史有效值保留，用户表单不提交这些参数。新建采用服务端现有策略，编辑省略隐藏字段时保留已有配置。

历史缺模型规则不批量补齐或运行。用户主动重新保存时采用已配置默认；规则原有启停状态、周期与历史跑次保留。仅缺预算而已有模型的规则使用内部默认，不再要求用户填写。

## 管理入口

独立本机页面为 `/admin`，普通导航不增加管理入口。管理页展示默认模型、接入状态、内部上限、技能专家、资料库目录，并可编辑单条自动化的内部配置、查看任务和跑次诊断。凭据仍由本项目 `.env` 维护，页面不提供密钥读取或编辑。

本轮沿用本机产品的现有访问方式，不新增角色鉴权。执行保护、用量记账、资料读取边界、费用确认与历史记录继续由原有服务处理。
