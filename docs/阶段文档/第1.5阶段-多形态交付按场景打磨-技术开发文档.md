# 第 1.5 阶段技术开发文档｜多形态交付按场景打磨

> 文档同步说明（2026-10-04）：本文为对应阶段的历史设计/验收记录；当前界面、功能范围和操作方式以[当前 PRD](../PRD/PRD-当前版本.md)、[真实工作流实现](融合界面与真实工作流.md)为准。新建任务和自动化均必填 `model_id`，旧无模型参数示例请按[当前 API](../API接口.md)更新后使用。

> 配套：`docs/PRD/PRD-1.1.md`、通用技术栈手册、前端技术栈手册。  
> 只覆盖「按场景推荐下载形态」；不提前做桌面端/新连接器。  
> 开发方法：先写本文档 → 改前端推荐按钮 → mock/人工验收。  
> 状态：**已通过**（2026-09-28，与 1.6 一并收口）。

## 一、阶段目标
- 交付：任务报告区按当前任务的 `skill_id`（或场景）**突出推荐一种下载格式**，其余格式仍可下。
- 产物：前端推荐映射 + 文案；可选小测。
- 验收：见第十一节。
- 不做：新导出引擎、自动写入资料库、飞书默认格式变更。

## 二、技术适配摘要
- 导出能力已有：Markdown / Word / Excel / PPT / 飞书。
- 本阶段只做「推荐哪一个」的产品呈现，不改后端导出实现。
- 开发路径：正式前端纵向切片。

## 三、技术栈与模型
- 仅前端；无新模型调用。

## 四、环境与配置
- 端口 3040 / 8040；无新配置。

## 五、项目结构
- `frontend/app/page.tsx`：按 skill 映射推荐下载按钮样式/顺序
- （可选）`frontend/lib/export-prefs.ts`：映射表

## 六、数据
- 无新持久化；读取任务已有 `skill_id`。

## 七、API
- 复用既有 `report` / `report.docx` / `report.xlsx` / `report.pptx`。

## 八、Prompt
- 无。

## 九、界面切片
- 报告区：主按钮为「推荐：Word/Excel/…」；次要为其他格式幽灵按钮。
- 推荐规则（产品默认）：
  - `table_analysis` → Excel
  - `weekly_report` / `meeting_minutes` / `email_draft` / `proposal_template` / `customer_reply` / `project_update` → Word
  - `competitor_research` / `industry_brief` / `meeting_prep` / `policy_brief` → Markdown（可再下 Word）
  - 未知 skill → Markdown

## 十、测试
- 手工：分别用表格分析、周报、竞品任务跑到有报告，确认推荐按钮文案与主次。
- 映射函数：`frontend/lib/export-prefs.ts`（纯函数，可人工对照规则表）。

## 十一、验收清单
- [ ] 表格分析任务报告区主推 Excel
- [ ] 周报/纪要/邮件类主推 Word
- [ ] 竞品/政策类主推 Markdown
- [ ] 其他格式仍可下载
- [ ] 桌面宽度下按钮不挤爆

## 十二、风险
- 无；仅 UI 优先级。
