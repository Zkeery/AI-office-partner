# 第 1.8 阶段技术开发文档｜飞书导出链接体验

> 文档同步说明（2026-10-04）：本文为对应阶段的历史设计/验收记录；当前界面、功能范围和操作方式以[当前 PRD](../PRD/PRD-当前版本.md)、[真实工作流实现](融合界面与真实工作流.md)为准。新建任务和自动化均必填 `model_id`，旧无模型参数示例请按[当前 API](../API接口.md)更新后使用。 Webhook 密钥、群通知设置、开放平台回调和应用身份导出已从普通用户界面移除；个人 OAuth 连接和主动导出保留。

> 配套：既有第 12 阶段飞书导出。  
> 产品反馈：① 期望进「用户自己的飞书文档」；② 链接要能复制，未登录可粘贴到浏览器再登录查看。  
> 状态：**已通过**（2026-09-28，产品经理：暂时不用改，先这样）。

## 一、阶段目标
- 交付：导出成功后展示**可复制、可打开**的飞书链接；服务端尽量打开「有链接可阅读」权限。
- 说明（产品事实）：当前仍用**应用凭证**创建文档（不是本机「飞书账号登录授权」）。真正写进「我登录的那个账号云空间根目录」需另开 **OAuth 用户授权** 阶段。
- 不做：飞书扫码登录、用户 OAuth（单独立项）。

## 二、改动
- `frontend/app/page.tsx`：去掉仅靠 `alert`；结果区展示标题 + 链接 +「复制链接」「打开」。
- `backend/app/services/feishu_export.py`：创建后调用权限接口，尽量设为链接可阅读。
- 测试：mock 导出仍通过；权限接口失败不阻断导出（记录在 meta）。

## 三、验收
- [x] 导出后页面上能一键复制链接（代码已具备）
- [x] 链接可在输入框选中；可「打开」；未登录流程已写明文案
- [x] 服务端导出后尝试开通链接可读（失败不阻断导出）
- [x] mock 自动化测试通过（飞书相关 2 条）
- [ ] 真实飞书：复制链接 → 浏览器打开 → 登录后能看文档（待点验）
