# 第 1.13 阶段技术开发文档｜任务搜索

> 承接：归档后任务变少，需要能按关键词找回。对标 WorkBuddy「搜索任务」。  
> 状态：**产品点验通过**（2026-09-29）。

## 一、阶段目标
- 交付：侧栏可搜；已归档也能搜到。
- 匹配规则：
  - 在办任务：标题或你输入的正文
  - 已归档：只按正文（避免「周报撰写规划」这类自动标题误伤）
  - 忽略正文末尾的「【已合并任务】」附录（里面列的是别人的标题）
- 搜索时：命中结果平铺展示（含已并入）；标题对不上关键词时，侧栏改显示正文摘要
- 不做：搜报告全文、跨设备、登录

## 二、改动
- API：`GET /api/tasks?q=`；有关键词时允许归档命中；LIKE 转义；正文匹配前去掉合并附录
- 前端：侧栏搜索；结果再过滤一层；归档标「归档」、搜索中的已并入标「已并入」；无标题命中时显示正文片段
- 测试：归档按正文命中；合并附录不误伤主任务

## 三、验收
- [x] 搜关键词能找到对应归档任务
- [x] 不相关的最新归档不会被带出来
- [x] 合并备注里的标题不会把无关主任务带出来（如搜「冒烟」不再出「飞书导出验收」）
- [x] 清空搜索恢复默认（不含归档）
- [x] mock 测试通过
