# 第 8 阶段技术开发文档｜工作区参考材料连接器

> PRD「更多连接器」的本机落地：从已授权工作区勾选文件，作为任务参考材料（与上传同配额）。  
> **不做**：网盘 / 邮箱 / 腾讯文档 OAuth、跨目录任意读写。

## 一、目标
- 计划确认前，可从授权工作区选择 txt/md/pdf/docx（合计仍最多 3 个参考文件）
- 选中后复制进任务 uploads，抽取文本摘要，执行时与手动上传同等对待

## 二、API
- `POST /api/tasks/{id}/workspace-refs`  
  Body：`{ "paths": ["notes.md", "docs/a.txt"] }`  
  成功返回更新后的 task；路径越界 / 类型不支持 / 超配额 → 标准错误结构

## 三、规则
- 必须已配置工作区根目录
- 路径经 `safe_resolve`，禁止逃逸
- 单文件 ≤20MB；扩展名与上传一致
- 文件名冲突时自动加前缀 `ws_`

## 四、界面
任务详情（plan_ready）在「上传参考材料」旁列出工作区文件，点「添加为参考」。

## 五、验收
授权工作区放一个 `.md` → 新建任务出计划 → 点添加 → 确认执行 → 报告能用到该材料（mock 下 uploads 列表可见即可）。
