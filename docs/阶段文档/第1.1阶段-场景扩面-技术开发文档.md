# 第 1.1 阶段技术开发文档｜场景扩面 + 最小数类

> 目标：首页可点场景交差；自由输入能粗识别；技能/专家更显眼；支持上传表格出分析结论。  
> 依据：`PRD-1.1.md`，D18=B。产品版本 **1.1**（相对 1.0）。

## 范围
- 场景卡：竞品调研、会议纪要、周报总结、表格分析
- `GET /api/scenes`、`POST /api/scenes/detect`
- 技能/专家目录扩充；上传允许 `.csv` / `.xlsx`
- 前端：新建页场景卡 + 货架芯片 + 识别提示；表格场景引导上传后重生成计划

## 不做
- 桌面客户端、企业多人、浏览器操控、新连接器账号体系

## 验收
1. 点「周报总结」→ 提示词与技能自动带上 → 生成计划成功  
2. 输入含「会议纪要」→ 识别到对应场景  
3. 表格分析：上传 csv/xlsx → 重生成计划 → 执行出报告  
4. mock 测试通过
