## 范围与验收

1. 步骤只有执行了对应操作、得到可检查结果才显示完成。未知工具失败；无输入的可选读取显示跳过及原因。失败、暂停、继续保留真实中间结果。
2. CSV 和 XLSX 在明确的容量限制内读取全部数据行、全部工作表；计算由程序完成。提供指标汇总、分组统计、月度变化、异常提示和真实图表。超过容量或存在无法计算的公式时明确失败，不按抽样结果冒充全量结论。
3. Excel 包含原始数据、计算结果、复算公式和原生图表；PPT 可包含可编辑的数据图表，长内容分页。现有 Word、Markdown 和飞书导出继续可用。
4. 报告支持全文或指定章节改写；章节之外保持原文。生成、改写、合并、恢复均保存版本；可查看版本差异、恢复旧版，冲突时阻止覆盖新版本。

延续本机单用户范围。现有自动化、飞书授权与导出、用户数据和配置保留；群通知保持默认关闭。本轮不扩展批量文件管理、通用插件市场或公网部署。

## 实现约定

- 延续 FastAPI / SQLite / Next.js 与本项目依赖环境，不更换技术栈。
- 本阶段增加报告版本表；历史报告首次读取或修改时纳入版本管理。后续模型选择增量在既有自动化表补充模型字段，并在任务计划元数据保存具体型号，详见[模型接入与选择](../模型接入与选择.md)。
- 表格分析快照持久化在任务产物目录；报告版本引用对应快照，恢复后导出使用该版本的数据。
- 新接口沿用 `/api/tasks/{id}`：`/analysis`、`/report/versions`、`/report/versions/{version}`、`/report/restore`；`/rewrite` 增加改写范围与预期版本字段，旧调用方式继续支持。
- API 返回统一错误结构。所有模型修改先验证结果，再保存新版本；旧稿不因失败丢失。

## 验证计划

- 后端：全量行列与多工作表、缺失值/非法数字、月度同比环比、图表数值、公式缓存缺失、未知工具、执行失败与续跑、局部改写边界、版本冲突、恢复与持久化。
- 前端：类型检查、Lint、生产构建；浏览器验证桌面和手机宽度，完整数据结果、章节改写、差异及恢复流程。
- 真实模型：使用本轮合成的非敏感销售数据做生成与局部改写，记录实际结果；不替代为 Mock。
- 交付证据：`docs/evidence/阶段1.25/`。测试结果与阶段状态在完成时填写。
