# 第 1.2 阶段技术开发文档｜写类补全 + 数类加深

> 文档同步说明（2026-10-04）：本文为对应阶段的历史设计/验收记录；当前界面、功能范围和操作方式以[当前 PRD](../PRD/PRD-当前版本.md)、[真实工作流实现](融合界面与真实工作流.md)为准。新建任务和自动化均必填 `model_id`，旧无模型参数示例请按[当前 API](../API接口.md)更新后使用。 表格当前为容量内全量计算与真实图表；报告支持章节修改、版本差异和恢复。

> 目标：首页可点「邮件稿」「方案模板」；自由输入能识别；表格分析计划与成稿含「图表说明」（文字描述，不真画图）。  
> 依据：`PRD-1.1.md`（写类补全 + 数类加深已并入该文，不另开 PRD-1.2）。工程子阶段仍记为 1.2。  
> 开发方法：沿用前端手册「场景卡 + 货架 + 识别」契约；后端只扩目录与 mock，不新开引擎。

## 范围
- 场景卡新增：`email_draft`、`proposal_template`
- 技能新增：`email_draft`、`proposal_template`；专家新增：`biz_writer`
- `table_analysis` 的 `plan_hint` / `report_hint` / mock 计划与成稿加深「图表说明」
- 识别关键词覆盖邮件 / 方案
- 前端：场景列表仍走 `GET /api/scenes`（自动出现新卡）；占位文案更新
- mock 自动化测试覆盖检测、计划与表格报告含图表说明

## 不做
- 真实图表渲染库、邮件真实发送、方案审批流
- 桌面端、企业多人、新连接器、1.3 货架逛搜

## 验收
1. 点「邮件稿」→ 提示词与技能带上 → 生成计划成功（标题/步骤含邮件）
2. 输入含「方案模板」→ 识别到 `proposal_template`
3. 表格分析执行后的报告含「图表说明」小节
4. mock 测试通过；前端可打开 http://127.0.0.1:3040 看到 6 张场景卡
