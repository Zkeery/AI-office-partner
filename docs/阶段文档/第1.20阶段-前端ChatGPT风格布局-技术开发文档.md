# 第 1.20 阶段技术开发文档｜前端 ChatGPT 风格布局

> 承接：1.19 自动化跑次可见已通过；本刀只改前端壳层视觉与导航落位，不砍能力。  
> 状态：**已通过**（2026-09-29）。产品目视验收通过（D）。

## 一、阶段目标
- 顶栏「新建 / 当前任务 / 资料库 / 自动化」横排导航迁入最左 **icon rail**（悬停出自定义气泡）；不再在任务侧栏重复文字入口。
- **补 icon rail**：最左侧始终可见的窄图标栏（线稿图标 + 当前项浅底圆角高亮 + **自定义悬停气泡**），映射新建 / 当前任务 / 资料库 / 自动化；「更多」仅占位。
- 侧栏显示/隐藏改为顶栏左侧折叠图标（ChatGPT 分栏图标），只控制 icon rail **右侧**的任务列表侧栏，收起后主区更宽；icon rail 本身不折叠。
- 中间工作区参考 ChatGPT：干净大主区、居中欢迎文案、底部大圆角输入条。
- 现有能力（新建任务、场景卡、任务列表、资料库、自动化、报告等）均可到达；本刀不做「聊天/工作」双模式 pill。

## 二、改动
- `frontend/app/page.tsx`
  - 整体改为「最左 icon rail + 可折叠任务/导航侧栏 + 右侧主框」；顶栏仅保留折叠按钮、品牌名、（侧栏收起时的紧凑新建）、右侧模型/检索提示。
  - **icon rail**（始终可见，**唯一四入口导航**）：房子=新建；时钟=当前任务（并展开侧栏侧重任务列表）；书架=资料库；叠方块=自动化；省略号=更多占位（无菜单）。
  - **自定义悬停气泡**（续刀）：去掉原生 `title`（保留 `aria-label`）；各按钮用 `data-tip` + `.icon-rail-btn::after` 黑底白字小圆角气泡，紧贴图标右侧出现，文案为 新建 / 当前任务 / 资料库 / 自动化 / 更多；悬停延迟尽量短。
  - 侧栏（去重后）：**不再**放「新建 / 当前任务 / 资料库 / 自动化」文字链接；展开后主要是任务搜索 + 任务列表（管理/合并保留）；由顶栏折叠按钮控制显隐。折叠后仍靠 icon rail 导航。
  - **导航去重：悬停出文字**（续刀）：去掉侧栏与 icon 重复的文字入口；导航只走 icon rail。
  - 新建页：`compose-stage` 居中欢迎 + 场景选择；底部 `compose-bar` 大圆角输入与开始按钮。
  - `toggleTaskRail` 记忆到 `localStorage`（`ai_office_task_rail_open`）；`startNewCompose` 清空草稿并进入新建；`goToTaskPanel` 供 icon rail（时钟）与任务列表点选共用。
- `frontend/app/globals.css`
  - 新增 `.icon-rail*` / `.app-sidebar` / `.app-topbar` / `.new-chat-btn` / `.compose-stage*` / `.compose-bar*` 等样式；`.desk` 改为横向 flex。（续刀后已去掉未再使用的 `.sidebar-link*`；icon rail 悬停改为 `data-tip` 自定义气泡）
- 不做：聊天/工作双模式、后端接口变更、git commit。
- **任务详情主区居中（续刀）**：去掉主区顶栏任务标题+状态+费用块，以及左右双栏空一边；有/无报告均用 `task-detail-stage`（`mx-auto max-w-3xl`）单栏居中。「成品报告」卡片顶栏右侧保留危险样式「删除」（确认后执行）；无报告时删除在操作行右侧次要位。状态弱化为报告头小字徽章，费用省略。过程区（计划/执行）同列居中。改 `page.tsx` / `globals.css`；不 commit、不碰 `.env`。


- **场景卡可滚指引（续刀）**：调研/写稿/数据三类场景网格保留约三行可视高度（`max-height` + `overflow-y: auto`）；内容超出时显示上下箭头（点按滚动约一屏）、底部淡出遮罩与「还有 N 个 · 下滑或点箭头」；滚到底或不足一屏时箭头/遮罩/提示消失。保留原有点选 `applyScene` 逻辑。改 `page.tsx` / `globals.css`；不 commit、不碰 `.env`。
