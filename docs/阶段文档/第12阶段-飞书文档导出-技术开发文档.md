# 第 12 阶段技术开发文档｜飞书云文档导出

> 目标：成功任务的调研报告可一键导出为飞书云文档，并返回可打开链接。  
> **不做**：腾讯文档、自动分享给他人、文档权限细配、双向同步编辑。

## 一、范围
- 仅 `succeeded` 且已有报告可导出
- 导出前须用户确认（对外写入）
- 默认 `FEISHU_MOCK=1`：不调真实飞书，写本地记录并返回模拟链接，便于工程验收
- 真实模式：用应用凭证创建 Docx，写入报告正文要点，返回飞书文档 URL

## 二、配置（`.env`，勿提交密钥）
```
FEISHU_MOCK=1
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_FOLDER_TOKEN=
```
- `FEISHU_FOLDER_TOKEN` 可选：指定云空间文件夹；空则创建在应用默认位置

## 三、API
- `POST /api/tasks/{id}/export/feishu`  
  Body：`{ "confirmed": true }`  
  成功：`{ "document_id", "url", "title", "mock": bool }`  
  错误：`REPORT_NOT_READY` / `CONFIRM_REQUIRED` / `FEISHU_NOT_CONFIGURED` / `FEISHU_EXPORT_FAILED`

## 四、界面
报告区增加「导出到飞书」；点击先确认，再请求；成功后提示链接（可复制打开）。

## 五、验收
1. mock 下：跑通任务 → 导出到飞书 → 返回含 `mock: true` 的链接  
2. 未确认 → `CONFIRM_REQUIRED`  
3. 无报告 → `REPORT_NOT_READY`
